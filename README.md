# Sign-up Form
<img width="1911" height="1045" alt="image" src="https://github.com/user-attachments/assets/9a7bd232-84ee-4c01-859f-09374cf54235"/>
A simple sign-up form built to practice modern CSS sizing techniques and custom font loading.
 
## Concepts Applied
- **`@font-face`** — Learned how to self-host a custom font so it renders consistently across different devices, instead of relying on system fonts or external font services.
- **CSS Units** — Explored various units (e.g. `rem`, `em`, `vw`, `%`) to size elements more dynamically rather than relying on fixed pixel values.
- **CSS Functions** — Used functions like `clamp()` and `calc()` to handle dynamic sizing and scale elements smoothly across different values.
